# 迁移编号登记

高鸣远维护 SQL 总稿和编号，成员先提交迁移提案。MySQL DDL 可能隐式提交，执行前停写并备份，不把整个迁移宣称成一笔可回滚事务。

| 编号 | 说明 | 当前状态 | 维护与使用 |
|---|---|---|---|
| 001 | 旧内容表增加寻物招领字段 | 已有脚本，保持不变 | 高鸣远维护；upgrade-db 使用 |
| 002 | 认领表与两类唯一索引 | 已有脚本，保持不变 | 高鸣远维护；upgrade-db 使用 |
| 003 | 权限种子提案 | 预留，尚未创建或应用 | 郭金滔提交，高鸣远审核编号与权限清单 |

后续编号在此登记，不多人同时创建同一个编号。没有结构或种子变化时写明无需迁移，不创建空 SQL。已有环境走增量脚本；新环境同步更新 init.sql。真实口令不进入种子，管理员初始化由身份模块从本地输入或环境获取一次性口令。

已用脚本不得随意改写；幂等行为、执行顺序、失败恢复和测试库结果应随提案提交。表结构与业务规则见 docs/database-schema.md 和 docs/r1-contracts.md。
