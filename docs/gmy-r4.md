## 可复现命令

在项目目录使用 PowerShell 7，准备 JDK 11、Maven、MySQL 8 与外部 Tomcat 9。填写忽略的 `src/main/resources/jdbc-local.properties`；不要把本机账号发给组员。

```powershell
./scripts/test-gmy-r4.ps1 -Port 8098
./scripts/package-gmy-r4.ps1 -VerificationPath '.local/本次验收目录/r4-verification.json'
```

验收目录实际采用复用的 `.local/gmy-r3-十二位编号` 隔离夹具命名，任务和输出明确记录为 GMY R4。测试在 finally 中停止专用容器，校验归属标记后删除夹具库和临时凭据。实际 `cms_content` 仅提供本机连接配置，不写入验收数据。

## 本人实现范围

- `GmyR4HttpSuite` 验证已实现的 FOUND 交接、LOST 找回、非法版本/越权/缺令牌、结案拒绝新申请、分类停用下旧申请延续以及安全审计。
- 专用 MySQL 触发器在交接第二步受控失败，检查申请、物品、时间、版本和其他申请的事务回滚，再移除触发器验证正常成功。该触发器仅存在于带归属保护的测试库。
- `GmyR4UpgradeProbe` 在独立夹具还原九表旧结构，调用与真实升级命令共用的 `MySqlCampusUpgrade.upgrade(Connection)`，验证非空旧内容拒绝自动回填、部分升级拒绝、空旧表升级、重复执行和已有用户分类及授权保留。
- `GmyR4Delivery` 将实际工作区源码、SQL、接口文档、图稿与可读 Git 历史打入候选包；校验源码指纹和已验收 WAR 哈希，排除本机配置、缓存、日志、Git 内部数据和本地工具。

以上是测试和交付工程，不把已有业务实现记为高鸣远本人编写。
