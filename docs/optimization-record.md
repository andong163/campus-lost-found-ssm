# 源码优化记录

日期：2026年10月12日。由 Codex 根据新选题与实际源码完成，高鸣远需复现并记录本人审查与修改。版本 0.2.0-SNAPSHOT。

| 问题 | 变更 | 验证方式 |
|---|---|---|
| 根 AOP 不自动处理子容器 Controller | MVC 也启用 AOP | 根切面拦截 MVC Controller 返回403 |
| MP 工厂未配置 XML 位置 | 加载 classpath*:mapper/**/*.xml | 同一 Mapper 的 XML与MP CRUD正常执行 |
| 批量输入缺少共同规则，小数可被转整数 | BatchIdsRequest及严格整数JSON | 空、重复、null、小数、超100拒绝，合法接受 |
| 就绪检查在 try 之前建立事务，连接失败可能500 | 移除不必要事务，内部捕获依赖失败 | 禁用连接池后503，新表缺失503 |
| 数据仍为通用文章结构 | 六个招领字段、认领表、角色显示及枚举 | 真实MySQL升级和约束回滚探针 |
| 初始化助手忽略配置URL端口 | 共用本地连接配置，限制目标库与地址 | 非默认端口解析、环境变量、错误目标和占位符用例 |
| 本地WAR压缩读取启动慢 | 调整SCI扫描并解包生产WAR | 独立WAR健康与404检查，实测耗时见验证记录 |
| 过滤器清理MDC会覆盖外层上下文 | finally恢复原requestId | 下游抛异常仍恢复外层ID |

## 业务接入范围

源码已与校园失物招领分工一致。新类属于公共约定和工具，没有代替郭金滔、孙睿、袁运轩、杨程实现注册登录、分类、内容、审核认领服务、审计或页面。

数据库唯一约束测试验证持久化保护，H2测试验证框架；不能当作认领业务并发测试或完成校园身份认证的证据。性能索引为结构设计，业务N+1优化和响应耗时需模块完成后实测。

## 合并前检查

核对所有修改、跑完整verify、查看实际测试报告、确认真实MySQL验证、检查WAR和源码包不包含私密配置及测试类。通过后合入本地develop；远程仓库未配置，不声称已推送。

本地SCI过滤策略参考 [Tomcat 9 Jar Scan Filter官方文档](https://tomcat.apache.org/tomcat-9.0-doc/config/jar-scan-filter.html)，保留Spring初始化器与WEB-INF/classes扫描。此策略属于本地容器工具，其他依赖的SCI需显式加入，JSP需调整TLD扫描。
