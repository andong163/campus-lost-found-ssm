# 第四轮后综合修复与验收

日期：2026-11-22。使用 JDK 11、传统 Spring / Spring MVC / MyBatis-Plus、MySQL 8 与外部 Tomcat 9；交付形式仍为 WAR。

## 修复内容

- 补齐新增寻物、招领草稿页面及导航入口，沿用已有接口和权限规则。
- 分类写操作串行执行，并在事务提交后释放锁；修复并发移动成环及分类移到根级时 NULL 未落库。
- 用户停用和角色移除共用管理员事务锁，保护最后一个有效管理员；用户、角色更新检查乐观锁影响行数。
- 审核、认领核实及撤销使用 `Integer.equals` 比较版本，修复版本超过 127 时将相同版本误判为冲突。
- 公共请求组件丢弃旧会话响应，登录、退出统一更新令牌；不同标签页切换账号时清空旧表单并刷新。
- 管理页重新登录后恢复工作区；列表及详情按请求顺序接收结果，防止慢响应覆盖最新查询。
- 新增页在分类请求前监听身份变化；旧保存响应不能把新账号跳转到旧内容。
- 旧审核、交接、日志页面复用公共请求组件；寻物联系方式的 ADMIN 规则与招领保持一致。
