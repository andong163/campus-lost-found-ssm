## 实际排查记录

1. 首次 Maven 无法下载 Spring BOM，错误包含 Permission denied: getsockopt。原因是执行环境的网络限制；允许官方 Maven 仓库访问后依赖可下载。该现象属于开发工具环境，不是项目 POM 缺少依赖版本。
2. 默认 Java 24 执行测试时，Spring CGLIB 代理出现 InaccessibleObjectException，提示 java.lang 未开放。切换到已校验的便携 JDK 11 执行课程工程；最终结果以 test-record.md 与 Surefire 报告为准。启动脚本明确要求 Java 11，避免组员沿用不兼容运行环境。
3. 初始化 SQL 人工核查时移除了引用 AUTO_INCREMENT 主键的分类 CHECK；父子循环由分类 Service 实现。该项是设计校正，不冒充已经发生的运行报错。
4. 本地数据库凭据采用外置私密文件；Maven 明确排除该文件，打包后再次核查 WAR 内容。凭据不写入 Git、报告或工具日志。
5. 独立启动 WAR 时，隔离后的容器类路径缺少 javax.annotation.PostConstruct，导致过滤器启动失败。补入 Tomcat annotations API、取消未使用的 JSP 默认配置，并增加打包后独立进程测试，防止测试类路径掩盖部署缺项。
