## 页面与行为

统一校园首页、公开检索和详情、发布编辑、本人信息、全站管理、审核、认领、交接、审计、分类、用户和角色管理。公共顶部导航集中提供入口；工作台下拉内保留管理入口，删除正文中重复的五项导航。

采用柔和灰蓝主色 `#486B7A`、灰白底 `#F5F7F7`、白色面板和浅灰蓝区域 `#E7EFF2`。首页底色为 `#EDF2F4`，搜索与最新信息区域使用白底、边框和深色标题 `#203640`，使标题、内容和背景有明确层次。桌面、平板与手机共用页面；宽表格在各自区域内滚动。

本次检查修复“我的认领”的权限矛盾：管理员在公共导航和详情中可以进入申请，但迁移页面曾错误禁止管理员申请。现在统一按公共权限判断（ADMIN 或 `claim:create`）展示并保护提交入口，实际资格仍由原服务端校验。补齐该页标题，增加四项允许/禁止申请的回归测试。前端检查入口现在执行 `src/test/js` 下全部测试文件，避免漏跑。

保留现有会话、CSRF、联系方式权限、账号切换清理、旧响应丢弃、版本冲突和实际交接流程。交接未完成前不会因审核通过而显示已归还；不可结案时禁用按钮并说明原因。快捷物品入口不改变服务端所有权与资格规则。

页面链接版本为 `ui=soft-20261128-3`，本地 CSS/JavaScript 引用按 SHA-256 内容摘要更新，减少缓存的新旧资源混用。本轮没有改动 Java、数据库脚本、数据库配置、Maven 依赖及 API 请求包装。
