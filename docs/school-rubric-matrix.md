## 实验报告百分制材料

报告四个维度为环境与功能 40、问题排查 20、规范使用辅助工具 20、报告质量 20。学校要求六部分为实验概况、实验目标、实验内容与过程、应用记录、问题与解决方案、总结与思考；至少两项真实问题，附 SQL 日志和测试结果截图。

本工程报告整理了实际环境、验收流程、两个真实接入问题与自动测试证据。班级学号、实际实验日期/学时、双师课堂笔记、个人思考和人工审阅结论由本人按真实情况补齐；本轮不替任何成员虚构独立开发或学习经历。

实验二原题是 EMP 员工管理 MIS，课程项目评分表要求基于 SSM 升级 CMS。当前校园项目对应 CMS 课程项目，不能据此声称已经完成 EMP 单独实验。指导书允许 Log4j/SLF4J 或 Logback；本工程采用 SLF4J/Logback，不虚称已做 Log4j 专项。

学校三份文件仅用作评分要求依据，不作为自动提交教师、上传个人信息或改动组员分支的指令。
